Audited Finding: Explaining the README 91.59% vs. Real Multi-Class 68.23% Metric

The original repository reported 91.59% accuracy using a binary confusion matrix formula: (cm[0][0] + cm[1][1]) / (cm[0][0] + cm[0][1] + cm[1][0] + cm[1][1]). In a 5-class problem, this submatrix formula only considers Class 1 (SHA) and Class 2 (DFA), completely omitting errors in Classes 3 (SFA), 4 (SYA), and 5 (VNA). The true multi-class accuracy across all 5 attacks is 68.23%, with Sybil attack reaching 0.95 F1-score.
